# Portfolio Muhamad Luqman Alfauzan

Website portfolio statis untuk menampilkan project software development dan data analytics.

## Preview lokal

Buka `index.html` langsung di browser, atau jalankan server lokal dari folder project:

```bash
python -m http.server 4173 --directory portfolio
```

Lalu buka http://127.0.0.1:4173.

## Deploy gratis

Folder ini dapat diunggah ke repository GitHub terpisah, lalu dipublikasikan melalui GitHub Pages, Netlify, atau Vercel. Tidak membutuhkan database atau server PHP karena seluruh halaman bersifat statis.
